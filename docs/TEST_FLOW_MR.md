# संपूर्ण चाचणी: ऑर्डर ते डिलिव्हरी (मराठी मार्गदर्शक)

हे चाचणी Supabase प्रकल्पावर करा. चाचणी ऑर्डर्स डेटाबेसमध्ये कायम राहतात (आर्थिक नोंदी हटवता येत नाहीत). लाँचपूर्वी रीसेट करावे लागेल.

## 0. तयारी
1. साइटवर "लॉगिन" → "नवीन खाते" → स्वतःचे खाते तयार करा (ईमेल पडताळणी चालू असेल तर ईमेल लिंक दाबा).
2. Supabase SQL Editor मध्ये (ईमेल बदलून) एकदा चालवा:
   update public.profiles set role='admin' where id=(select id from auth.users where email='तुमचा@ईमेल.com');
3. साइटवर बाहेर पडून पुन्हा लॉगिन करा. वरती "अॅडमिन" दिसेल.

## 1. सेटिंग्ज
अॅडमिन → सेटिंग्ज: व्यवसायाचे खरे नाव, फोन, ईमेल भरा. "ऑर्डर घेणे चालू" टिक करा → जतन करा.
(कमिशन आणि पुनरावलोकन स्थिती आत्ता बदलू नका.)

## 2. उत्पादन
अॅडमिन → उत्पादने व स्टॉक → नवीन उत्पादन भरा, "दुकानात दाखवा" टिक करा → जतन. नंतर "स्टॉक आला" दाबून संख्या टाका.

## 3. ग्राहक म्हणून ऑर्डर
दुसऱ्या ब्राउझर/गुप्त विंडोमध्ये दुसरे खाते तयार करा. उत्पादन कार्टमध्ये टाका → ऑर्डर करा → UPI निवडा → पत्ता भरा.

## 4. अॅडमिनकडून पूर्ण करा
अॅडमिन → ऑर्डर्स:
1. "पेमेंट मिळाले" (संदर्भ क्रमांक टाका) → ऑर्डर "निश्चित".
2. → प्रक्रियेत → पाठवले (कुरिअर, ट्रॅकिंग टाका) → पोहोचले.
3. ग्राहकाच्या "माझ्या ऑर्डर्स" मध्ये स्थिती आणि ट्रॅकिंग दिसले पाहिजे.

## 5. रिटर्न
ग्राहक: ऑर्डर पोहोचल्यानंतर "परत करा" → संख्या व कारण. अॅडमिन → रिटर्न/रिफंड → मंजूर → पैसे परत दिल्यावर "रिफंड नोंदवा".

## 6. कमिशन (फक्त पुनरावलोकन मंजूर झाल्यावर)
कमिशन बंद ठेवा. कायदेशीर/अनुपालन पुनरावलोकन झाल्याशिवाय सेटिंग्जमध्ये "मंजूर" निवडू नका.
